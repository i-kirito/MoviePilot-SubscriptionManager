# MoviePilot FollowUp

`续作跟进` 是一个 MoviePilot v2 插件，用媒体库和订阅历史检查系列续作，并在满足提醒窗口时自动添加订阅。

这个仓库是 `i-kirito` 的独立维护版，当前版本为 `1.6.3`。业务处理链路沿用已验证的 1.6.2 运行版本，本次重点改善插件详情页：

- 顶部显示插件与 Trakt 日历状态；
- 用四张概览卡片展示当前订阅、历史记录、待处理提醒和 Trakt 事件；
- 将运行周期、提醒窗口、媒体库范围整理成运行概况；
- 将自动订阅记录和待处理提醒分成带数量、说明和滚动表格的区块；
- 失败事件与处理中事件分开提示，保留失败后的下一轮重试语义。

## 配置要点

- `启用插件`：开启每日或自定义 cron 检查。
- `命中自动订阅`：命中续作时自动创建订阅；关闭后仍可保留检查与提醒。
- `检查订阅历史`：把历史订阅纳入续作扫描范围。
- `接入 CookieCloud Trakt 个人剧集日历`：只读取 MoviePilot 全局 CookieCloud 中的 `trakt.tv` Cookie，并仅处理能够确认 TMDB ID 的事件。
- `选择媒体库`：为空时扫描所有已配置媒体库。
